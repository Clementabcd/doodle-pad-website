Features

Everything you need to draw

A full-featured drawing studio packed into a clean, native macOS app.

✏️

Freehand Drawing

Smooth bezier-curve strokes with adjustable size, opacity, and colour. Draw naturally with pressure sensitivity.

🔷

Shape Tools

Line, Rectangle, and Ellipse tools with a dedicated Forms panel. Click-drag to create perfect shapes.

📑

Layer System

Add, delete, reorder, and toggle visibility. Each layer has its own thumbnail preview and opacity control.

🪣

Flood Fill

Intelligent scanline fill with boundary tracing and simplification. Perfect for colouring closed areas.

💧

Eye Dropper

Sample any pixel colour from your canvas with one tap. Automatically switches back to Draw mode.

🎯

Selection Tool

Tap to select individual strokes, drag to reposition them. Delete, or switch tools to deselect.

📤

Multi-Format Export

Export to PNG, JPEG, TIFF, BMP, or vector PDF — all from a single popover or the File menu.

💾

Save & Open

Native .doodlepad format preserves every stroke, layer, image, and setting. Auto-saves every 30s.

↩️

Unlimited Undo / Redo

Full layer-state history. ⌘Z to undo, ⇧⌘Z to redo — never lose your work.

📐

Grid & Background

Toggleable grid overlay, custom background colour, and transparent canvas support.

🔍

Zoom & Pan

Scroll to pan, slider or ⌘+/⌘- to zoom. Reset to 100% or fit to window in one click.

🌍

5 Languages

Fully localized in English, French, German, Spanish, and Japanese. Switch via system settings.

🖨️

Printing

Full-resolution canvas printing via the standard macOS print panel. ⌘P to print.

⚙️

Preferences

Customize default canvas size and auto-save behaviour in a native preferences panel.

🖼️

Drag & Drop Images

Drop image files directly onto the canvas. Each becomes a new layer with embedded image data.

Technology

Built for macOS.
Made with Swift.

Doodle Pad is a native macOS application written entirely in Swift and SwiftUI. It uses Swift Package Manager for builds, NavigationSplitView for its professional sidebar layout, and native Core Graphics for pixel-perfect rendering and export.
